# Variante 04 — Deep Clean

**Indicación:** Piel grasa / poros / comedones / congestión

## Objetivo

Descongestionar y mejorar la apariencia de poros y superficie cutánea.

## Protocolo

### Limpieza
AlumierMD Clarifying Cleanser.

### ProFacial
PS1 → PS2 → PS3

### Paleta
U1–U2.
Extracción selectiva.

### Tratamiento
Según valoración: AlumierMD Detox Clear, cuando predomine congestión.

### Celluma
No necesariamente.
Si existe componente inflamatorio: Celluma Acne.

### Finalización
Producto calmante/hidratante apropiado + SPF.

## Frecuencia

3–4 sesiones, cada 2–3 semanas.
