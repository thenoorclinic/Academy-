# Academy — Protocolos Faciales

Documentación de los 12 protocolos faciales de la clínica, basados en AlumierMD, PRO XN y Celluma, organizados por tipo de piel/indicación.

## Índice de protocolos

| Nº | Protocolo | Indicación | Frecuencia |
|----|-----------|------------|------------|
| 01 | [Skin Reset](protocolos/01-skin-reset.md) | Piel normal / mantenimiento / piel apagada | 3 sesiones iniciales cada 3–4 sem., luego mantenimiento cada 6–8 sem. |
| 02 | [Hydra Barrier](protocolos/02-hydra-barrier.md) | Deshidratación / barrera alterada / sensibilidad | 3 sesiones cada 2–3 sem. |
| 03 | [Rosacea Recovery](protocolos/03-rosacea-recovery.md) | Piel reactiva / eritema / tendencia a rosácea | 4 sesiones cada 2–3 sem. |
| 04 | [Deep Clean](protocolos/04-deep-clean.md) | Piel grasa / poros / comedones / congestión | 3–4 sesiones cada 2–3 sem. |
| 05 | [Acne Control](protocolos/05-acne-control.md) | Acné activo / piel grasa / inflamación | 4–6 sesiones, según evolución |
| 06 | [Acne + Marks](protocolos/06-acne-marks.md) | Acné controlado + hiperpigmentación postinflamatoria | 4–6 sesiones |
| 07 | [Pigment Control](protocolos/07-pigment-control.md) | Manchas solares / PIH / tono irregular | 4–6 sesiones, con reevaluación |
| 08 | [Bright Up](protocolos/08-bright-up.md) | PIH / pigmentación / tono irregular / componente inflamatorio | 4–6 sesiones |
| 09 | [Melasma Care](protocolos/09-melasma-care.md) | Melasma / hiperpigmentación recurrente | 4–6 sesiones, con reevaluación clínica |
| 10 | [Retinoid Renewal](protocolos/10-retinoid-renewal.md) | Arrugas / textura / fotoenvejecimiento | 3–4 sesiones, según tolerancia |
| 11 | [Firm & Renew](protocolos/11-firm-renew.md) | Piel madura / flacidez / pérdida de firmeza / fotoenvejecimiento | 4 sesiones cada 2–3 sem. |
| 12 | [Post-Treatment Recovery](protocolos/12-post-treatment-recovery.md) | Recuperación después de procedimientos (postpeeling, postláser, postmicroneedling, etc.) | 1 sesión postprocedimiento, repetible según evolución |

## Convenciones usadas en los protocolos

- **ProFacial (PS1/PS2/PS3):** fases del dispositivo/protocolo ProFacial referidas en cada variante.
- **Paleta (U0/U1/U2):** nivel de intervención/extracción indicado.
- **RF:** radiofrecuencia; solo se indica como fase diferenciada cuando el protocolo lo permite explícitamente.
- **Celluma:** modo de terapia LED (Recovery, Acne, Aging/Wrinkles) recomendado en cada variante.

## Nota

Estos protocolos son guías clínicas de referencia. Cada variante señala condiciones de exclusión, suspensión o adaptación cuando corresponde (p. ej. no combinar peelings profesionales en la misma sesión salvo protocolo oficial que lo contemple, o suspender ante intolerancia). La valoración profesional individual siempre prevalece sobre la guía.
